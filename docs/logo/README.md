# EOS logo

Final form locked 2026-11-02 by owner decision.

This directory holds the canonical EOS logo pair, and only this pair:

- `eos-logo-dark.webp`: the primary. A single continuous cyan neon tube
  spelling lowercase "eos" (straight-crossbar e, round o, smooth s), with
  no mounting rings, over a plain dark background.
- `eos-logo-white.webp`: the companion. The same tube letterforms over a
  plain white background.

The workspace drafts directory (`eos-logo-drafts/`) holds exploration
variants from the design rounds (wafer, silicon, prism, and earlier neon
versions). It is NOT committed, and none of those variants are canonical.
Only the two files above are the EOS logo.
